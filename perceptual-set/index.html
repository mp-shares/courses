知觉实验 · A Lab on Perceptual Set

Perceiving is believing.

你先相信，才"看见"。

我们以为感官是一台忠实的摄像机——先看见世界，再决定信不信。可知觉常常是反过来的：你带着预期、经验和当下的情境走近一个东西，这套知觉定势（perceptual set）已经替你决定了，你究竟会看到什么。往下滑，下面几个小实验会当场把你"设定"一次。

01  /  定义

什么是知觉定势what is a perceptual set

知觉定势，是一种预先形成的心理倾向：它让你倾向于以某种特定方式去知觉一个事物，同时忽略掉其他同样成立的可能。换句话说，在你真正"看到"或"听到"某样东西之前，大脑已经带着一整套假设在待命——这套假设会主动筛选、组织，甚至改写你实际感知到的内容。

关键在于：进到你眼睛里的原始信号可以完全不变，变的只是你把它组织成什么。这就是心理学里说的自上而下加工（top-down processing）。

可以把它想成一副看不见的眼镜：你从没摘下过，也很少意识到它的存在，但它先于你的每一次观看，悄悄决定了镜片那头的世界长什么样。
实验一  /  图形与背景 · figure–ground
RUBIN · 一张图，两种现实
你先决定看什么？
同一张黑白图。选一个提示试试——被设定去看脸，脸就先跳出来；被设定去看杯，杯就成了主角。哪块是"图形"、哪块退成"背景"，不由墨迹决定，而由你带来的定势决定。

机制  /  是谁在给你"设定"

四样东西，在替你调镜片what shapes a perceptual set

  • 期望expectation

    有人先告诉你"这杯水很苦"，你喝下去更容易尝到苦味。预期被说出口的那一刻，定势就已经装好了。

  • 情境context

    邻近的线索会改写解读——就像上面那团墨迹，左右是字母还是数字，直接决定了它是 B 还是 13。

  • 文化与经验culture & experience

    老厨师能从一锅汤里尝出新手完全察觉不到的层次。经验越厚，镜片磨得越细，看见的东西也越不一样。

  • 情绪与动机emotion & motivation

    饿的时候，模糊的图案更容易被看成食物。你此刻想要什么、怕什么，也在悄悄拨动镜片。

原理  /  为什么会这样

知觉是"猜"出来的why perception runs top-down

自上而下加工top-down processing
大脑不是被动接收一堆像素，而是拿已有的知识和预期，去补全、去解释感官输入。信号不够时，缺口由预期来填。
预测编码predictive coding
大脑不停地预测下一刻的感官信号，再用"预测和现实的误差"来修正。你感知到的，很大程度上是大脑当下的"最佳猜测"，而不是原始输入本身。
确认偏误的知觉版confirmation bias
你更容易"看见"那些支持你已有信念的东西。这不只是解释上的偏心，它一直往前渗透，改变了你最初到底看到了什么。
于是the upshot
两个人面对同一个场景，可能真的"看到"了不同的东西——差别不止在事后的解读，而是在知觉发生的那一瞬间就已经分岔了。
